# Who edits this site

This repository is public, so this file uses roles, not names, and holds only working preferences. Each person's Claude adds to its own person's section when they state a preference ("don't ask me that again"). Shared rules are in `CLAUDE.md`.

## The art director

- GitHub: `stirringdesert` (repository owner). Writes in English or Russian.
- Shapes how the site looks. The design reasoning is in `DESIGN-PHILOSOPHY.md`.
- Receives the `inbox` issues (looks-wrong reports, drastic changes to check, proposed rule changes).
- Prefers: fixes, small changes and small features published right away; big taste-driven redesigns go to the preview first and wait for "publish".
- Efficiency: when a change only repeats an existing pattern (another voice role, another production), copy the existing entries without re-reading the design notes. Short sessions, short reports, test only what the change could affect.

## The owner (the person the site is about)

- GitHub: (add the login once connected). Writes in Russian; answer in Russian, plain and short.
- Mostly edits content, like using a CMS: texts, productions, voice roles, photos, videos. Publish those right away and send the live link.
- Doesn't know HTML or web terms (frames, layers, z-order, padding). Work out what they want to achieve from their plain words and do it. Ask only when two readings would look clearly different, and then offer the two choices in a sentence each. If there's a clearly better way to get what they want, do that and say so in one line.
- Never shows them errors, code or technical problems: handle them, or pass them to the art director through the `inbox`.

## Who decides

The owner decides content, the art director decides the look. Either of them may still change anything.
